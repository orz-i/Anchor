# 历史规格档案

`docs/specs/` 保存过去阶段的需求、设计与任务拆解，用于追溯“当时为什么这样设计”，不是当前产品契约或待执行 roadmap。

本目录中的文档可能包含已经退役的 Tauri/Svelte desktop、Actions、旧工具名、旧协议版本、GitNexus 工作流、过时目录结构或曾经计划但最终未采用的方案。这些内容应按文档自身日期/阶段理解，不得据此恢复兼容桥、重新暴露旧入口，或覆盖当前源码行为。

判断当前 Anchor 行为时，优先级为：

1. 当前源码与机器验证；
2. [`docs/README.md`](../README.md) 及其链接的当前专题手册；
3. `docs/project-context/` 当前架构说明；
4. 本目录历史规格，仅用于设计追溯。

需要把历史方案重新引入产品时，应作为新的显式设计决策重新评审，而不是把旧规格视为兼容要求。
