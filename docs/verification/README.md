# 历史验证档案

`docs/verification/` 保存特定日期、特定 commit / Catalog / 平台环境下的验证证据。它们用于回溯已发生的测试、现场问题和修复过程，不是当前运行时契约。

因此，本目录可能合法出现已经退役的产品入口、协议、工具名、Tauri/Actions/GitNexus 等历史术语。读取这些记录时必须同时查看文件日期和基线 commit；若与当前源码或正式手册冲突，以当前源码和 [`docs/README.md`](../README.md) 为准。

新增验证记录应：

- 明确日期与代码基线；
- 描述当次验证事实，不把历史兼容行为写成永久支持承诺；
- 若验证导致当前产品契约变化，同时更新正式专题手册，而不是只更新本目录。
